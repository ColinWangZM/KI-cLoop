# Data contents, policy, and regeneration

This repository versions a compact processed kinetics dataset for direct
download and analysis. Large, licensed, or sensitive source artifacts remain
excluded.

## Included data

| Path | Contents |
|---|---|
| `kinetics/route_kinetic_parameter_summary.csv` | Route-level ODE-inverse PINN parameters, product R² values, and bootstrap confidence intervals |
| `kinetics/route_evaluation_summary.csv` | Yield, selectivity, productivity, kinetic-accessibility, greenness, and overall route scores |
| `kinetics/route_condition_comparison.csv` | Best measured and model-recommended conditions for each route |
| `kinetics/condition_optimization_summary.json` | Compact condition-search results and consensus recommendations |
| `kinetics/route_product_prediction_pool.csv` | Experimental-versus-predicted product concentrations used for parity/error analysis |
| `kinetics/routes/` | Per-route parameters, metrics, prediction tables, training histories, bootstrap samples, and profile likelihoods |
| `kinetics_route_knowledge.json` | Machine-readable kinetics knowledge consumed by KGRAG |
| `nodes_with_context_kinetics.csv` | The same kinetics results serialized as graph-retrieval node contexts |

See [`kinetics/README.md`](kinetics/README.md) for schemas, route identifiers,
interpretation notes, and analysis examples.

## Excluded data

The following stay outside Git because they are large, licensed, sensitive,
or reproducible from source code:

- model weights, LoRA checkpoints, Chroma databases, caches, and logs;
- Pistachio-derived source data and full organic-reaction context tables;
- raw experimental Excel files and complete route training-input tables;
- full combinatorial condition-search candidate pools;
- proprietary reactor-model files, paper drafts, and PowerPoint decks;
- generated LLM responses and judge outputs.

Local-only files expected by the remaining workflows include:

| File | Produced or consumed by |
|---|---|
| `node_identities_mof.pickle` | input to `create_vectordb.py` |
| `node_identities_or.pickle` | input to `create_vectordb_or.py` |
| `nodes_with_context_mof.csv` | MOF retrieval and local evaluation |
| `nodes_with_context_or.csv` | `augment_or_applications.py` |
| `nodes_with_context_or_YT.csv` | optional second OR source |
| `nodes_with_context_or_applications.csv` | generated by `augment_or_applications.py` |
| `material_application_index.json` | generated by `augment_or_applications.py` |

Paths can be changed in `kg_rag/config.yaml` or with the environment variables
documented in `.env.example`. Keep private data outside the Git working tree
whenever possible.
