# Data policy and regeneration

Large or sensitive artifacts are intentionally not versioned. In particular,
this repository excludes model weights, Chroma databases, Pistachio-derived
source data, full organic-reaction context tables, experimental kinetics
inputs, paper drafts, and generated evaluation responses.

Expected local files include:

| File | Produced or consumed by |
|---|---|
| `node_identities_mof.pickle` | input to `create_vectordb.py` |
| `node_identities_or.pickle` | input to `create_vectordb_or.py` |
| `nodes_with_context_mof.csv` | MOF retrieval and local evaluation |
| `nodes_with_context_or.csv` | `augment_or_applications.py` |
| `nodes_with_context_or_YT.csv` | optional second OR source |
| `nodes_with_context_or_applications.csv` | generated by `augment_or_applications.py` |
| `material_application_index.json` | generated by `augment_or_applications.py` |
| `kinetics_route_knowledge.json` | generated by `export_kinetics_context.py` |

All paths can be changed in `kg_rag/config.yaml` or through the environment
variables documented in `.env.example`. Keep private data outside the Git
working tree whenever possible.
